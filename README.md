## V3 case-study system
Each case-study card now opens `case-study.html?id=XX`. The detail page contains a consistent research structure: challenge, technology, implementation, accounting/financial impact, lessons and sources. Four high-detail records (JPMorgan Chase, Intuit, BlackLine and NPCI/UPI) contain specific research notes; the remaining records use clearly framed analytical summaries rather than fabricated company-specific metrics. Replace/add sources as your research progresses.
